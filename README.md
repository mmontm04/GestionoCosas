# GestionoCosas - Guía de Configuración
Para que la aplicación funcione en tu ordenador, sigue estos pasos:

## 1. Requisitos previos
* Tener instalado el **JDK 17** o superior.
* Usar un IDE con soporte para Java.

## 2. Configuración en del espacio de trabajo
1. Abrir el IDE correspondiente de java.
2. Selecciona el archivo `mysql-connector-j-9.5.0.jar` he intalar la libreria en el proyecto que está en la carpeta `Code/lib`.

## 4. Ejecución
* Abre `src/app/Main.java` y ejecutalo.
